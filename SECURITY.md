# Security Policy

Do not create a public issue for a suspected vulnerability. Report it through the repository's private security
advisory channel and include affected versions, reproduction steps, impact, and any proposed mitigation.

Production secrets, merchant certificates, device credentials, customer data, access tokens, database snapshots, and
packet captures containing identifiers must never be attached to an issue or committed to the repository.

The supported release line is the latest production release. Security fixes may be backported only when an active
customer deployment cannot upgrade immediately.
