# 微信小程序发布说明

## 已交付范围

`apps/miniapp` 是原生微信小程序，零运行时第三方依赖。消费者第一次使用“微信快捷登录”时由服务端执行 `code2Session` 并自动创建账号，不需要再注册用户名和密码。小程序只保存平台短期访问令牌、轮换刷新令牌、租户 ID 和消费者 ID，不保存 AppSecret、商户私钥或支付密钥。

当前真实流程包括：

- 扫描充电端口二维码并读取真实场站、设备、端口、状态和费率；
- 首次充电前阅读并同意后台发布的有效协议；
- 幂等创建订单、发送启动/停止指令并查看真实订单状态；
- 调用微信 JSAPI 支付并等待服务端验签回调确认，不在客户端伪造支付成功；
- 查看钱包余额、支付记录，申请并查看电子发票；
- 提交和查看客服工单；
- 访问令牌过期后自动轮换，会话失效后要求重新登录；
- 退出登录和消费者账号注销。注销前强制检查进行中订单、欠费和钱包资金，账务凭证按法规留存，微信身份解绑且所有刷新会话撤销。

仓库和发布包不包含演示用户、测试场站、模拟订单、假支付结果或占位业务数据。

## 发布前必须提供

1. 已认证微信小程序的真实 AppID、AppSecret、主体、服务类目和管理员/开发者权限。
2. 已备案且证书可信的真实 HTTPS API 域名，最终地址必须以 `/api/v1` 结尾。
3. 已在平台后台创建且状态为启用的业务租户；小程序租户编码必须与服务端 `WECHAT_TENANT_CODE` 完全一致。
4. 微信公众平台“开发管理 → 开发设置”中的 `request` 合法域名；协议和电子发票页面域名还需加入业务域名。
5. 后台发布的真实服务协议和隐私政策（HTTPS 全文地址及 SHA-256 摘要）。
6. 需要收费时提供微信支付 APIv3 商户资料、回调域名和已审核的分账关系；不收费联调可以暂不启用支付，但支付按钮不会模拟成功。
7. 需要订阅通知时提供已审批的模板 ID；不需要时保持空数组。
8. Windows 微信开发者工具。上传命令会复用开发者工具中的登录态，不读取或保存代码上传私钥。

## 生成发布配置

在仓库根目录运行：

```powershell
.\config-manager.cmd wizard
.\config-manager.cmd validate
.\config-manager.cmd export-miniapp
```

向导中至少完成以下设置：

- 启用微信小程序登录；
- 填写 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 和 `WECHAT_TENANT_CODE`；
- 配置 `develop`、`trial`、`release` 三套环境，正式环境 API 必须为公网 HTTPS 且以 `/api/v1` 结尾；
- 微信开发者工具不在默认目录时填写 `MINIAPP_DEVTOOLS_CLI_PATH`，例如 `D:\Program Files\Tencent\微信开发者工具\cli.bat`。

命令会生成两个 Git 忽略文件：

- `apps/miniapp/src/deployment.config.js`：开发版、体验版和正式版各自的 API、租户和通知模板；
- `apps/miniapp/project.private.config.json`：真实 AppID 和强制域名校验配置。

AppSecret 只注入服务端容器，绝不会写入小程序文件。

## 本机预览和真机验收

1. 启动微信开发者工具并登录拥有该小程序权限的微信账号。
2. 导入目录 `apps/miniapp`，不要只导入 `src`。
3. 确认开发者工具显示的 AppID 正确，并保持“校验合法域名”开启。
4. 点击“预览”，使用真机完成下列验收：
   - 新微信用户首次登录自动建号，重复登录仍是同一账号；
   - 无效、过期和跨租户二维码被拒绝；
   - 未签协议不能启动；同一端口并发启动只有一笔成功；
   - 断网、超时、令牌过期和退出登录都有明确恢复路径；
   - 真实桩启动、计量、停止、结算和异常告警完整闭环；
   - 微信支付取消、成功、重复回调、退款、分账及分账回退状态正确；
   - 发票、工单、退出和账号注销行为正确。

## 一键上传代码

先确保微信开发者工具处于登录状态，然后执行：

```powershell
.\miniapp-upload.cmd 2.0.0 "微信首发"
```

脚本会重新校验统一配置、重新生成发布文件、定位开发者工具 CLI，再上传正式代码包。版本号必须是 `主版本.次版本.修订版本` 格式。缺少 AppID、正式 API、租户、开发者工具或登录权限时会终止，不会上传错误包。

代码上传后，必须由小程序管理员在微信公众平台完成体验、隐私保护指引、服务类目、审核提交和最终发布；微信审核不能由仓库脚本绕过。

## 上线门禁

满足以下条件前不能公开收费运营：真实桩机协议验收、真实微信支付和分账验收、支付回调验签与主动查单恢复、退款和分账回退、协议与隐私合规审核、备份恢复演练、压力测试、告警值班和 ICP 备案/行业资质。详细清单见 `production-readiness.md`。
