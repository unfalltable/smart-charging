# 生产商用门禁

当前 V2 已具备生产软件主流程，但不等于已经取得上线验收结论。以下能力已落入代码：

- 微信小程序登录、平台令牌轮换/复用检测，管理端 OIDC PKCE 与租户 RBAC。
- 场站、设备、端口、费率、订单、计量、停止、计费、支付、退款、账务、对账、结算、钱包、发票。
- 告警、工单、客服、协议签署、通知 outbox、审计、请求追踪和分布式限流。
- 微信支付 APIv3 官方 SDK 下单、验签解密、退款与回调，支付/退款主动查单恢复；设备密钥加密分发与轮换。
- 微信订阅消息授权、模板映射、access token 共享缓存、outbox 发送与指数退避重试。

受外部资质、凭据、真实设备或生产基础设施约束，正式收款和接入真实设备前仍必须全部通过：

- 真实桩协议适配、断网续传、命令 ACK、乱序/重复消息和断电恢复测试。
- 微信支付商户验收、回调白名单/验签、退款、日账单、分账及异常补偿的真实环境验收。
- OIDC 管理员 MFA 策略、角色矩阵复核、密钥托管、审计留存和个人信息合规评审。
- 若生产沿用自托管 Keycloak：启用可信 HTTPS、MFA、受管数据库、备份恢复、会话与暴力破解告警，并完成至少双实例故障切换；本机 Compose 的单实例身份容器不能直接作为公网高可用部署。
- PostgreSQL 主从/备份恢复演练，Valkey 与 NATS 高可用故障切换演练。
- PostgreSQL 迁移/运行账号分离并验证运行账号无超级用户和 `BYPASSRLS`；NATS 启用 TLS、账号权限与 JetStream 多副本。
- 峰值容量压测、72 小时稳定性测试、SAST/SCA/镜像扫描、渗透测试和依赖许可证复核。
- 灰度发布、数据库向前兼容迁移、回滚预案、监控告警、SLO 与值班响应流程。

首台实体桩应先在隔离验收环境跑完整闭环，不直接处理真实资金。通过验收后再切换生产商户和正式域名。
`ops/compose.local.yaml` 使用生产鉴权逻辑并保持空库，但仍是单机配置：数据库单账号、NATS 未启用生产集群鉴权，禁止直接用于公网生产。设备网关只有提供真实 mTLS 材料后才会启动。

支付宝小程序及支付宝支付仍属于下一渠道阶段；核心订单、账务和 `PaymentGateway` 契约已经渠道无关，但没有把未经
完整安全审计的支付宝 SDK 依赖塞进当前微信首发包。该项不影响微信首发，但不能宣称支付宝端已经交付。
